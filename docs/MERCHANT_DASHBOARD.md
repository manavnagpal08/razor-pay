# Merchant Dashboard

## Overview
Phase 08 introduces the operational window for the merchant to observe the AI's autonomous behavior and its impact on conversion.

## Architecture
- **API**: `GET /api/merchant/dashboard` aggregates core transactional and event metrics.
- **Service Layer**: `AnalyticsService` handles the computational SQL logic natively on the server side to protect raw event data and enforce read-only execution for analytics.
- **Frontend**: A Next.js route `/merchant` serving a clean, fintech-inspired view displaying Revenue, Conversions, and a real-time `AgentAction` Ledger.

## AI Traceability
The dashboard renders the `AgentAction` table directly, allowing the merchant to see:
- What the AI did (e.g., `CROSS_SELL_RECOMMENDATION`).
- The reasoning string generated by the LLM.
- The `policy_result` determined by the internal guardrail engine (e.g., `BLOCKED` or `ALLOWED`).
